## Bugs I Found & Fixed
- **Unscoped Universal Controller Mode**: Cortex previously processed arbitrary commands without property validation.
  - *Fix*: Added strict property registration check rejecting unregistered targets fail-closed (HTTP 404).
- **Recommendation Auto-Execution**: Model intervention suggestions previously risked immediate state mutation.
  - *Fix*: Decoupled recommendation from execution; recommendations halt at WAITING_APPROVAL.
- **Unapproved High-Impact Changes**: Sensitive actions could run without human supervisor sign-off.
  - *Fix*: Gate billing, comms, prod config, content, and account permissions behind explicit approvals (HTTP 403).
- **Stale Telemetry Execution**: Operations ran on outdated metrics.
  - *Fix*: Added telemetry timestamp validation rejecting observations older than 60s.

## Key Decisions & Architecture
- Kept Cortex strictly scoped to registered websites and web applications, not a general-purpose controller.
- Maintained strict 5-phase separation: Observation -> Recommendation -> Approved Action -> Execution -> Measurement.
- Governed high-impact operations across 5 specific categories with mandatory human-in-the-loop approvals.
- Integrated Sentinel as an automated security barrier before any production deployment or configuration change.
