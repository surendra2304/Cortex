## Bugs I Found & Fixed
- **Authentication Fail-Open in Mock Mode**: The system allowed mock credentials in production environments.
  - *Fix*: Added `validate_production_secrets()` ensuring production strictly fails closed.
- **Silent Mock Connector Fallback**: Connectors silently simulated success when credentials were missing.
  - *Fix*: Implemented explicit `ConnectorMode` (`LIVE`, `MOCK`, `DISABLED`) failing closed in production.
- **SSRF in Outbound Webhook**: Third-party webhook calls lacked destination IP address validation.
  - *Fix*: Integrated `PolicyEngine.validate_url` blocking private, loopback, and reserved destinations.
- **Unbounded WebSocket Connections**: WebSockets were unauthenticated and broadcasted across all tenants.
  - *Fix*: Added tenant-scoped connection managers, connection limit capping, and token authentication.
- **Dangling Coroutine Warnings**: Naive result checks caused unawaited coroutine warnings in Python 3.11.
  - *Fix*: Added explicit `hasattr` checks and awaited asynchronous session query results.

## Key Decisions & Architecture
- All production routes require explicit RBAC roles (`Role.CORTEX_ADMIN`, `Role.CORTEX_OPERATOR`, `Role.CORTEX_VIEWER`).
- Tenancy is derived strictly from authenticated credentials, never from client request bodies.
- Audit records and memory entries are scrubbed with recursive redaction before persistence.
- State machine checkpoints use SHA-256 state hashing with optimistic version concurrency.
