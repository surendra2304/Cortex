## Bugs I Found & Fixed
- **Synchronous vs Asynchronous ToolBus Callables**: Sync tool executors failed when awaited directly.
  - *Fix*: Integrated runtime `inspect.iscoroutinefunction()` checks in `ToolBus.execute()`.
- **CRM Mock Receipt ID Prefix Mismatch**: `test_mock_integrations` expected `crm_mock_rec_` but HubSpot executor emits `hubspot_mock_`.
  - *Fix*: Updated assertion in `tests/unit/test_mock_integrations.py` to match actual mock ID format.
- **Stripe Webhook Signature Skip in Mock Mode**: Must parse raw bytes before any JSON decoding.
  - *Fix*: Router reads `request.body()` before any parsing; mock path bypasses HMAC for dev safety.

## Key Decisions & Architecture
- Stripe SDK is synchronous; calls wrapped in `run_in_executor` to keep event loop unblocked.
- Zendesk uses `httpx.AsyncClient` directly — no executor needed (native async REST calls).
- Stripe webhook receiver returns HTTP 200 to Stripe even on Redis failure; failure is logged for replay.
