## Bugs I Found & Fixed
- **Synchronous vs Asynchronous ToolBus Callables**: Sync tool executors failed when awaited directly.
  - *Fix*: Integrated runtime `inspect.iscoroutinefunction()` checks in `ToolBus.execute()`.
- **Missing Mock Receipt Formatting**: Mock tool executions previously lacked structured receipt metadata.
  - *Fix*: Standardized mock receipts with `msg_mock_` IDs, `crm_mock_rec_` tags, and `mode: "mock"` flags.
- **Connection Error Handling in Demo Script**: Script crashed abruptly if local API was not running.
  - *Fix*: Wrapped execution in `httpx.ConnectError` handlers printing clear local startup instructions.
