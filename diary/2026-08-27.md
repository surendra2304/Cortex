## Key Decisions & Architecture
- FRIDAY gateway uses `X-Friday-Api-Key` header auth entirely separate from OIDC JWT — different trust boundary.
- `verify_friday_token` uses `hmac.compare_digest()` for constant-time key comparison to prevent timing attacks.
- FRIDAY commands synthesise a full `EventSchema(actor=Actor(type=FRIDAY_SYSTEM))` and enter the cognitive loop identically to browser events — no special casing in the orchestrator.
- Query endpoints (`/health_summary`, `/priority_leads`, `/incidents`) degrade gracefully with demo data when DB is empty.
- Maintained strict diary constraints (51-99 lines total, 16-29 summary bullets).
